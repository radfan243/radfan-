# NEXORA AI — Trading Intelligence

واجهة تحليل سوق فاخرة ومتجاوبة، مبنية كـ MVP مستقل داخل هذا المستودع.

## ما تم تنفيذه
- لوحة Dashboard RTL بطابع Dark Premium.
- بيانات سوق عامة مباشرة من Binance بدون مفاتيح API.
- BTC/USDT مع قائمة أصول قابلة للتوسعة.
- فريمات 15m و1h و4h و1d.
- رسم حركة السعر.
- محرك Confluence تجريبي يجمع EMA20/EMA50 وRSI والحجم والزخم وATR.
- إشارات BUY / SELL / WAIT بالعربية.
- مستوى قوة للإشارة وخطة دخول/وقف/أهداف مرجعية.
- بحث وفلاتر للعملات.
- تنبيه واضح أن النظام لا يضمن الربح أو دقة 100%.

## ملاحظات مهمة
هذا الإصدار **تحليلي فقط** ولا ينفذ صفقات ولا يطلب مفاتيح Binance. محرك التحليل الحالي rule-based وليس نموذج تعلم آلي مدربًا. مرحلة AI الحقيقية وBacktesting وPaper Trading تأتي بعد تثبيت الأساس واختبار الاستراتيجية.

التصنيف الشرعي ليس فتوى؛ يجب تعريف قائمة الأصول ومعاييرها من مصدر شرعي موثوق.

## التشغيل
يمكن فتح `index.html` مباشرة في المتصفح. يحتاج اتصال إنترنت للوصول إلى Binance API وخط Cairo.
