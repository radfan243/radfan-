# GOLDAN AI — AI SMART TRADING

واجهة تداول وتحليل عربية RTL بطابع Dark Premium، تعمل كواجهة ويب مستقلة داخل هذا المستودع.

## الأقسام
- **التداول:** لوحة السوق والأسعار والشموع الحية.
- **التحليل:** EMA20/EMA50 وRSI14 وATR14 والحجم والزخم مع إشارة شراء/بيع/انتظار.
- **القراءة:** شرح عملي لطريقة فهم المؤشرات والإشارات.
- **السجلات:** صفحة للسجلات المحلية داخل المتصفح.
- **الإعدادات:** مصدر البيانات والتنبيهات الأمنية الأساسية.
- **Backtesting / Paper Trading:** موجود في `phase2.html` للاختبار التاريخي والمحاكاة دون أموال حقيقية.
- **ML Lab:** موجود في `ai-lab.html` كمرحلة بحثية منفصلة.

## البيانات والتحليل
الأسعار والشموع في لوحة التداول تُجلب من Binance Public API عبر HTTPS، والحسابات تتم داخل المتصفح. محرك الإشارة الحالي **rule-based** وليس وعدًا بتوقع المستقبل، وقوة الإشارة ليست احتمال نجاح معايرًا.

## الأمان
- لا توجد مفاتيح Binance سرية داخل المشروع.
- لا يتم تنفيذ أوامر شراء أو بيع حقيقية من لوحة التداول الحالية.
- التداول الورقي والـBacktest منفصلان عن التداول الحقيقي.
- لا توجد دقة 100% مضمونة؛ يجب اختبار الاستراتيجية وإدارة المخاطر قبل استخدام أموال حقيقية.

## التشغيل
افتح `index.html` في المتصفح مع اتصال إنترنت. GitHub Pages يمكنه نشر المشروع مباشرة.


## GOLDAN AI XAUUSD PRO (تطوير مستقل)
- `gold-analysis.html`: مساحة تحليل الذهب مع مخطط تفاعلي وأدوات اتجاه/شعاع/أفقي/عمودي/مستطيل/Fibonacci/Fib Extension/قناة وملاحظات.
- `goldan-forex-engine.js`: محرك حسابي مستقل لمؤشرات EMA20/50 وRSI14 وATR14 واختراق نطاق سعري.
- `goldan-live-feed.js`: قارئ شموع MT5 عبر HTTPS.
- `goldan-chart.js`: مخطط شموع وحجم مع حفظ الرسومات محليًا.
- `mt5/GOLDAN_XAUUSD_Bridge.mq5`: Expert Advisor للقراءة فقط يرسل OHLC ولا ينفذ صفقات.
- `bridge/`: واجهة FastAPI لاستقبال شموع MT5 وتقديمها للتطبيق. راجع `bridge/DEPLOY.md`.

### متطلبات تفعيل أسعار الذهب الحقيقية
يلزم نشر الجسر على Windows VPS/خدمة Docker آمنة، وضبط `GOLDAN_BRIDGE_TOKEN` كمتغير سري، ثم تشغيل EA على MT5 Desktop وإدخال رابط HTTPS في صفحة الذهب. لا يستطيع تطبيق MT5 على Android وحده تشغيل Expert Advisor. مخطط TradingView المضمّن للمقارنة البصرية فقط؛ بيانات الإشارات تأتي من MT5.

### حدود الإشارات
ماسح الإشارات يشترط توافق 3 أطر من M5/M15/H1/H4 مع تأكيد M5. درجة التوافق ليست احتمال ربح أو توصية مضمونة. لا توجد أوامر تداول حقيقية ولا حاجة لكلمة مرور حساب الوساطة.

- `tradingview/GOLDAN_AI_XAUUSD_Alerts.pine`: مؤشر Pine أصلي لإشارات TradingView عند إغلاق الشمعة، يرسل تنبيهات إلى Webhook الجسر عند إعداد `GOLDAN_TV_WEBHOOK_TOKEN`. TradingView في الإطار المضمّن للمقارنة البصرية؛ تنبيهات Pine هي قناة الإشارة الثانية.


## XAUUSD بدون VPS (الوضع الافتراضي)
- صفحة الذهب تستخدم Yahoo Finance مباشرة من المتصفح دون خادم وسيط أو VPS، وتخزن الشموع التاريخية مؤقتًا في IndexedDB على الهاتف.
- M5 وM15: النطاق المتاح عبر المصدر العام عادةً آخر 60 يومًا؛ H1: حتى سنتين؛ H4 يُنشأ بتجميع شموع الساعة.
- الأسعار من مصدر عام وقد تكون متأخرة أو تختلف عن سعر OneRoyal؛ لا تعتبر سعر تنفيذ أو تسعير وسيطك.
- قد يمنع المتصفح أو مزود الإنترنت الوصول المباشر إلى Yahoo Finance بسبب CORS أو قيود الشبكة؛ عندها تعرض الصفحة نسخة مخزنة سابقًا إن وجدت.
- MT5 bridge يبقى خيارًا متقدمًا اختياريًا، وليس مطلوبًا لتشغيل وضع Yahoo Finance. لا يتطلب الوضع الافتراضي كلمة مرور وسيط ولا ينفذ أوامر.
